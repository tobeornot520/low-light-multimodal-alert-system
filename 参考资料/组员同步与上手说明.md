# 组员同步与上手说明

## 1. 同步包说明

本同步包是 2026-08-29 经过筛选的源码快照，用于让五名组员获得一致的工程、文档和申报材料。它不是 Git 历史归档；日常协作应以公开 GitHub 仓库的最新默认分支为准。

```text
snapshot_date: 2026-08-29
base_commit: 见 PACKAGE-MANIFEST.md
package_type: source-and-docs working-tree snapshot
verified_tests: 153 passed
static_check: Ruff passed
```

压缩包内 `project/` 是可运行项目及当前有效资料，`申报材料/` 额外提供经费申报准备稿的快捷副本。

## 2. 当前项目定位

> 面向固定、授权场景，利用 RGB/NIR 多模态感知与边缘计算，稳定确认特定人员，对具有明确物理定义的人员行为进行早期识别，并形成可解释的分级预警和结构化事件数据。

当前真正可运行的主链路仍是单路 RGB。NIR 已有数据协议和保守融合内核，但没有实机适配、同步数据或跨谱性能结论。

## 3. 当前能力

- 摄像头探测与实时预览；
- YuNet 人脸检测；
- 人脸质量门控；
- SFace 特征和授权模板；
- 开放集身份状态；
- 多帧跟踪和身份投票；
- 区域进入、停留和离开事件；
- 本地 JSONL 日志；
- 无窗口离线视频回放、逐帧遥测和审计报告；
- 实验 manifest 和多模态 manifest 校验；
- 多模态保守融合决策；
- 身份阈值、开放集和事件指标内核；
- 153 项自动化测试。

当前未完成：真人实采、目标设备验收、阈值冻结、RGB/NIR 实机融合、行为早期识别数据与评测、可靠远程通知和目标边缘设备部署。

## 6. Python 环境

建议使用 Python 3.11。不要共享虚拟环境目录，每名成员在自己的机器重新创建。

### Windows PowerShell

```powershell

py -3.11 -m venv .venv311
.\.venv311\Scripts\python.exe -m pip install --upgrade pip setuptools wheel
.\.venv311\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv311\Scripts\python.exe -m pip check
.\.venv311\Scripts\python.exe -m pytest
.\.venv311\Scripts\python.exe -m ruff check .
```

## 8. 首次验证

没有摄像头和模型时，仍可先运行自动化测试。需要实际检测、注册、识别、监控或回放时再下载模型并准备设备/非敏感输入。

```bash
python run.py --help
python run.py validate-manifest config/experiment.example.yaml
python run.py validate-manifest config/multimodal-manifest.example.yaml
```

默认 `config/default.yaml` 没有警戒区域，运行 `monitor` 或 `replay` 前必须复制配置并设置 `events.zones`。

## 9. 数据与安全规则

1. 只采集明确同意的参与者。
2. 真人数据、模板、标注和日志只进入被 Git 忽略的受控目录。
3. 不通过普通 Git、聊天附件或公共网盘传递生物特征数据。
4. 注册、开发和测试必须按采集会话隔离。
5. 数据 manifest 只使用 `person-a` 等项目内编号。
6. 阈值和行为规则只在开发集选择，冻结测试集不用于反复调参。
7. 对外展示前单独确认素材许可和删除期限。

## 10. 建议的协作步骤

1. 每名成员先完成环境安装和测试。
2. 阅读“项目会后共识与下一阶段路线”。
3. 确认各自的工作包、输入、输出和复核人。
4. 在独立 Git 分支开发，提交前运行测试和 Ruff。
5. 公共数据结构变更同时更新上下游、示例和测试。
6. 未明确认领或没有验收标准的功能不进入当前阶段。

## 11. 校验同步包

Linux/macOS：

```bash
sha256sum -c FILES.sha256
```

Windows PowerShell 可以逐项使用：

```powershell
Get-FileHash -Algorithm SHA256 .\project\run.py
```

若整体 ZIP 校验值与外部 `.zip.sha256` 不一致，应重新获取压缩包，不继续使用其中内容。
